Architecture · C4-style overview

Agent Firewall

A local security layer for coding agents: it follows every process the agent starts, and a dangerous action is judged and stopped before it runs — at the exec boundary and at the system-call boundary.

Seven layers, one shared contract

  • Every crate talks through the types of af-core
  • No layer touches a platform detail of another
  • A macOS or Windows collector swaps in without changes elsewhere

Two enforcement boundaries

  • Entry of execve — the new program never ran
  • Seccomp stop of a held open / connect — no byte written, no packet sent
  • A path is sound to refuse with, never to allow with

Deterministic by design

  • No model, no network, no clock in the decision path
  • The recorded trace replays to the same verdict

01 · System context — C4 level 1

The firewall sits between the agent and the machine

One command starts the session. The firewall traces the whole process tree, judges each action against policy, and either lets it run, refuses it with an ordinary permission error, or kills the tree. Only the kernel and the developer are outside the loop.

02 · Containers — C4 level 2

Seven crates, one contract, two decision lanes

The launcher starts the session and the monitor reports one normalized Event per kernel stop. The decision lane answers with a verdict; the recorder and the engine never write memory directly — the caller applies the effects, in event order.

03 · Kernel boundary — C4 level 3

What the monitor sees, and how a stop becomes a verdict

One BPF filter, installed once at the session root, holds connect and write-opens; every descendant inherits it. The collector reads registers and tracee memory while the call has not happened, then the performer answers: continue, refuse with EPERM, or kill the tree. A refused call never runs — which is why a path is sound to refuse with, and never to allow with.

04 · Decision path — C4 level 3

Provenance, rules, memory, approval — and the replay that re-runs it

The engine reads only facts: session, action, process, ancestry. It returns a verdict plus memory effects, never writing anything itself. Windows use the event time, not the clock. agent-firewall replay feeds a recorded trace through the same engine and gets the same verdicts.
